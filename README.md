## 🧑‍💻 About the Project

This portfolio represents my work as a developer, highlighting my journey, technical skills, and real-world projects. It is built with a strong emphasis on smooth animations, responsive design, and modern frontend practices.

The goal of this project is to create a professional online presence that is both visually appealing and functional across all devices.

---

## ⚙️ Tech Stack

- React.js (Vite)
- Tailwind CSS
- Framer Motion
- Lucide React Icons
- EmailJS (for contact form)
- JavaScript (ES6+)

---

## 🎯 Features

- ⚡ Fully responsive design (mobile, tablet, desktop)
- 🌙 Dark/Light mode toggle
- 🎬 Smooth animations using Framer Motion
- 🧭 Floating navigation for easy section access
- 🧑 Hero section with animated portrait reveal
- 📂 Projects showcase section
- 🛠 Skills & experience sections
- 🎓 Education timeline
- 📬 Contact form integrated with EmailJS
- 🚀 Optimized performance and clean UI
